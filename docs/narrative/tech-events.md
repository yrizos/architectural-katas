# Tech Events

## Purpose

This page is a list of the tech events where we run the workshop. It is a list and not a set of separate event pages.

The reader leaves knowing which events we have run and which are coming. The page has no ticket, registration, or join us calls to action, per `docs/writing.md`.

## Key Information

Every entry carries the same fields.

- Event name and link.
- Session title.
- Date, time, venue, and room.
- Language and level.
- Facilitators.
